## 1. 前置条件

- 浏览器打开 **https://www.doubao.com**，已登录账号（右上角显示"用户XXX"）。
- 登录态保存在浏览器 profile 中，后续会话复用。
- 视频生成消耗**每日免费额度**；部分功能需要付费（见第 9 节）。

## 2. 进入视频生成模式

1. 打开 <https://www.doubao.com>（主对话页）
2. 在主对话**输入框下方的快捷工具栏**中点击 **「视频生成」** 按钮
   - 工具栏默认显示：快速、视频生成、PPT 生成、AI 表格、图像生成、帮我写作、翻译、深入研究、更多
   - **若窗口较窄，工具栏会折叠**：只剩「快速」「更多」，需先点 **「更多」** 展开菜单，再点「视频生成」
3. 进入视频生成面板后，输入框上方出现：
   - **「视频生成」** 标题（其上方为无文本的上传按钮，见第 6 节）
   - **「模型 Seedance 2.0 Mini」** 按钮（模型切换；**会记忆上次选择**，实测本次会话初始显示 Fast）
   - **「自动 · 10s」** 按钮（画幅/时长设置）
   - **输入框**（多行，可输入提示词）

## 3. 输入提示词

- 在输入框中直接输入**视频描述**，支持多行
- 按 **Enter** 提交（无需点击任何按钮）
- 提示词建议格式：**主体 + 动作 + 场景 + 风格 + 画质**，例如：
  > 一只戴宇航员头盔的橘猫在月球表面漫步，远处是蔚蓝的地球，阳光洒落，3D 动画电影感镜头，高清画质
- 提交后自动创建新会话，侧边栏「最近」出现新条目（标题自动取提示词摘要，如"橘猫月球漫步视频生成"），对话中出现「生成视频：<提示词>，10s」

## 4. 模型选择与切换

点击 **「模型 Seedance 2.0 Mini」** 按钮，弹出模型菜单（上下滚动查看全部 4 款）：

| 模型 | 菜单描述 | 消耗 | 免费/付费 |
|---|---|---|---|
| **Seedance 2.5** | 升级 · 旗舰视频标杆 | **5 倍消耗** | 🔒 **付费**（实测：选中弹订阅窗） |
| **Seedance 2.0** | 升级 · 进阶画面表现 | 2 倍消耗 | 🔒 **付费** |
| **Seedance 2.0 Fast** | 快速出片选择 | 默认 | ✅ **免费**（实测：选中立即生效） |
| **Seedance 2.0 Mini** | 日常生成使用 | 默认 | ✅ **免费**（默认选中） |

切换方法：
1. 点击「模型 当前模型名」按钮
2. 在弹出菜单中点击目标模型
3. 按钮文字实时更新为「模型 Seedance 2.0 Fast」等
4. 若选择付费模型（2.5 / 2.0），会弹出「订阅豆包专业版」窗口，需付费解锁

## 5. 参数设置（画幅/时长）

点击 **「自动 · 10s」** 按钮，弹出参数菜单：

**① 画幅比例**（按钮单选，点击即生效，按钮文字实时更新）：

| 选项 | 说明 |
|---|---|
| 自动 | 默认，根据内容自动选择 |
| 3:4 | 竖屏（偏方） |
| 4:3 | 经典屏 |
| 9:16 | 手机竖屏（短视频） |
| 16:9 | 横屏（标准视频） |
| 1:1 | 方形 |
| 21:9 | 超宽屏（电影感） |

**② 视频时长**（滑块，点击滑块后可用键盘方向键/End/Home 调整）：

| 滑块 value | 秒数 | 免费/付费 |
|---|---|---|
| 0-6 | 4s-10s（每 1s 一档） | ✅ 免费，即时生效 |
| 7-11 | 11s-15s | 🔒 **付费**，弹订阅窗，不生效 |

> **实测结论（2026-08-13）：滑块 value 0-11 对应 4s-15s，每档 1 秒。** 11s 是第一档付费边界；调到付费档（含 End 到最大值 15s）会弹「订阅豆包专业版」，且时长不生效（保持 10s，按钮文字不变）。免费用户保持 ≤10s。

选择后按钮文字变化，例如「16:9 · 10s」表示横屏 10 秒。

## 6. 上传图片（图生视频）

视频生成面板支持**上传参考图片**（图生视频）：

- 上传按钮位置：**「视频生成」标题上方**的无文本方形图标按钮（36×36）
- 支持格式：**.jpg / .png / .jpeg / .webp**，支持多选
- 上传后图片缩略图出现在**输入框上方**，图片旁有移除按钮（点击可删除）
- 上传图片后输入提示词，描述图片应如何动起来，即可生成基于参考图的视频

> 注意（2026-08-13 实测）：该按钮在 MCP 快照中显示为**无文本 button**（可定位 uid，位于「视频生成」标题上方）。正确上传方式见 8.4：**直接 `upload_file` → 该按钮 uid**。不要用 `evaluate_script` 触发 `btn.click()`——那会弹出系统的文件选择窗口。

## 7. 提交与等待结果

1. 输入提示词（可选带参考图）后按 Enter
2. 系统回复：「**视频生成已提交**，本次使用 Seedance 2.0 Mini 生成，**预计等待 10 分钟**。视频生成好后，我会主动发送给你。本次生成将消耗每日免费额度。」（消息上方为「生成视频：<提示词>，<时长>」记录；会话标题自动取提示词摘要）
3. 生成是**异步队列模式**：提交后等待（约 10 分钟量级），等待期间消息显示「**视频生成中**」，完成后视频自动出现在该会话中，可播放、下载
4. 注意：**输入框行的无文本按钮是发送按钮**（点击即提交当前内容+参考图），不要误触

### 7.1 下载生成的视频（2026-08-13 实测）

生成完成后，消息卡片中的视频由 **xgplayer** 播放器渲染，video 元素**可能延迟挂载**（第二条等了约数分钟才出现，React 渲染时机不定）——需要**轮询查询** `document.querySelectorAll('video')` 直至数量达到预期。

下载方法（无需页面下载按钮，实测可靠）：

1. `evaluate_script` 获取 video 的 `currentSrc`（douyin CDN 带签名直链）：
   ```js
   () => [...document.querySelectorAll('video')].map(v => v.currentSrc || v.src)
   ```
2. 用 curl 下载到本地（**必须带 doubao Referer 头**，否则 CDN 可能拒绝）：
   ```bash
   curl -o video.mp4 -H "Referer: https://www.doubao.com/" "<video-src-url>"
   ```
3. 校验：MP4 文件头应为 `ftyp`（`66 74 79 70`）。

> 注意：视频 URL 带签名参数（`l=...`、`rc=...`），签名与登录会话绑定、可能有时效，建议生成完成后尽快下载。

## 8. 使用 Chrome MCP 的完整操作步骤

以下为通过 Chrome DevTools MCP（`chrome-devtools`）自动化操作的完整流程：

### 8.1 进入视频生成面板

```
1. navigate_page  →  https://www.doubao.com/chat
2. take_snapshot  →  找到输入框下方快捷工具栏
   - 窗口宽度足够时：「视频生成」按钮直接可见
   - 窗口较窄时：先点「更多」展开，再点「视频生成」
3. 点击「视频生成」按钮（snapshot 中的 button "视频生成"）
4. take_snapshot  →  确认面板出现：
   - button "模型 Seedance 2.0 Mini"
   - button "自动 · 10s"
   - textbox（输入框）
```

### 8.2 切换模型（以 Fast 为例，已实测）

```
1. 点击 button "模型 Seedance 2.0 Mini"   → 弹出菜单
2. take_snapshot → 菜单出现 4 个 menuitem：
   "Seedance 2.5 升级 旗舰视频标杆 • 5 倍消耗"
   "Seedance 2.0 升级 进阶画面表现 • 2 倍消耗"
   "Seedance 2.0 Fast 快速出片选择"
   "Seedance 2.0 Mini 日常生成使用"
3. 点击 menuitem "Seedance 2.0 Fast 快速出片选择"
4. take_snapshot → 按钮变为 "模型 Seedance 2.0 Fast"（立即生效，无弹窗）
   ⚠️ 若点 2.5/2.0：弹出「订阅豆包专业版」dialog（iframe），需点"返回"关闭
```

### 8.3 设置参数（以 16:9 为例，已实测）

```
1. 点击 button "自动 · 10s"                → 弹出菜单
2. take_snapshot → 菜单含比例按钮组 + slider：
   button "自动" / "3:4" / "4:3" / "9:16" / "16:9" / "1:1" / "21:9"
   slider（时长）
3. 点击 button "16:9"
4. take_snapshot → 按钮变为 "16:9 · 10s"（比例生效）
5. 调时长：
   - 点击 slider 聚焦 → press_key 方向键/End 调整
   - ⚠️ 调到 15s（最大值）会弹「订阅豆包专业版」且不生效，免费用户保持 10s
```

### 8.4 上传图片（图生视频，已实测）

上传按钮是**无文本纯图标按钮**（快照中显示为无文本 button，位于「视频生成」标题上方）。正确做法（2026-08-13 实测）：

```
方法（实测可行，无副作用）：
1. take_snapshot → 找到「视频生成」标题上方的无文本 button（上传入口）
2. upload_file → { uid: <该无文本 button uid>, filePath: "本地图片路径" }
3. take_snapshot → 输入框上方出现 image "xxx.jpg"（参考图缩略图）
```

> ⚠️ **不要**用 evaluate_script 触发 `btn.click()`（会弹出系统文件选择窗口）。
> ⚠️ 删除已上传图片：缩略图旁有删除按钮（DOM class `delete-btn-*`），可用
> `evaluate_script` 点击删除（安全，不弹窗）。
> ⚠️ 上传后输入框行的**无文本按钮是发送按钮**（点击即提交），不是删除按钮——误点会直接提交当前内容。

### 8.5 输入提示词并提交（已实测）

```
1. fill → { uid: <输入框 textbox uid>, value: "一只橘猫在月球漫步，3D动画风格，高清画质" }
2. press_key → Enter
3. take_snapshot → 页面跳转新会话，显示「视频生成已提交…预计等待 10 分钟」
4. 等待：可用 wait_for 监听 "生成完成" 类文本（注意超时），或稍后查询会话
```

### 8.6 风控处理

- **语义验证码**：新环境首次提交可能弹出字节验证码 iframe
  （rmc.bytedance.com/verifycenter，如"请选择所有符合描述的图片并拖拽到下方"）
- 需**暂停自动化并请用户人工完成**（拖拽图片），完成后验证码不再弹出
- 可观察 snapshot 中是否出现 Iframe "验证码" 判断
