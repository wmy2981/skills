# 识图子代理提示词模板

调度识图子代理时使用本模板。SKILL.md「2. 子代理识图」的分派规则规定：**每个子代理负责连续 10 张图片**，批次按页码顺序分派，**把整批页内容写入同一个 Markdown 文件**；识别必须用 **Sonnet 模型**。

本流程面向**纯文字书籍**（典型如小说）：子代理输出**纯文本行**（原文一个自然段 = Markdown 一行，段落间空行），不使用列表 / 表格 / 代码块等结构标记；章节结构靠锚点表达。

## 使用方法

把模板中的 `{N}`、`{起始页}`、`{结束页}`、`{批次序号}`、`{pages_dir}`、`{raws_dir}` 替换为实际值，作为子代理任务传入。

| 占位符 | 含义 | 示例 |
|---|---|---|
| `{N}` | 本批次页数（末批不足 10 取实际页数） | 10 |
| `{起始页}` | 本批次第一页页码（从 1 起） | 1 |
| `{结束页}` | 本批次最后一页页码 | 10 |
| `{批次序号}` | 本批次序号（从 1 起），用于输出文件命名 | 1 |
| `{pages_dir}` | 拆页图片目录（extract 输出） | book/pages |
| `{raws_dir}` | 识图输出目录 | book/raws |

## 命名规范

每个子代理把自己负责的整批页写入**同一个文件**，命名：`batch_{批次序号:03d}.md`（批次序号从 1 起，顺序对应页码顺序）。

批次切分示例（默认 10 页一批）：

| 子代理 | 负责页面 | 输出文件 |
|---|---|---|
| #1 | page_0001 ～ page_0010 | batch_001.md |
| #2 | page_0011 ～ page_0020 | batch_002.md |
| #k | page_{(k-1)*10+1} ～ page_{k*10}（末批不足 10 则到末页） | batch_{k:03d}.md |

图片文件固定命名 `page_XXXX.png`（XXXX 为 4 位零填充页码）。文件内**每页（含空白页、无正文页）**都以一行页码注释 `<!-- PAGE XXXX -->` 起始，**其中的 XXXX 必须严格等于该图片文件名的页码**（读 `page_0005.png` 写 `<!-- PAGE 0005 -->`），用于主代理校对时定位与页码覆盖核验；若某页无可识别正文，仅保留该页 PAGE 标记、不写内容；批次内页码标记逐页连续、不可跳过。

## 提示词模板

```markdown
你是扫描书识图子代理。负责读取 {N} 张连续页面图片，把整批内容转录为纯文本行 + 锚点，写入同一个文件。

【负责页面】{pages_dir}/page_{起始页:04d}.png ～ page_{结束页:04d}.png（共 {N} 页，严格按此顺序逐页处理）
【输出文件】{raws_dir}/batch_{批次序号:03d}.md

逐页执行：**严格按 page_XXXX.png 文件名的数字顺序**逐一读取（page_0001 → page_0002 → … → page_{结束页}），不得颠倒或跳号；每读完一页，把识别内容写入输出文件。注意：输出文件内容必须始终包含截至当前已处理的所有页的完整内容（整批累积，不得只保留当前页、不得覆盖丢失前面的页）。
图片文件固定命名 `page_XXXX.png`（XXXX 为 4 位零填充页码）。每页（含空白页、无正文页）都以一行页码注释 <!-- PAGE XXXX --> 起始，**其中的 XXXX 必须严格等于该图片文件名的页码**——读到 `page_0005.png` 就写 `<!-- PAGE 0005 -->`，与图片一一对应、不可错位；若该页无可识别正文，只写该 PAGE 标记、不写内容。写完后以一个空行分隔进入下一页；整批按页码顺序连续写入同一文件，页码标记逐页连续、不可跳过。

每页必须遵守的内容规范：

一、输出形式（纯文本行）
1. 只输出识别到的文档内容。原文中的一个自然段 = Markdown 中的一行；段落之间用空行分隔。
2. 禁止：任何列表、表格、代码块标记；禁止任何解释、说明、思考过程、结论、"这是第 X 页"之类元评论；禁止页眉页脚文字；禁止对图片中插图的描述性旁白。
3. 跨页段落连接：若一个自然段被分页截断（前一部分在本页末尾、后一部分在下一页开头），在上一页该段行尾加 `__`、在下一页该段行首加 `__`，两部分之间不放空行；后期校对会去掉 `__` 并合成为一段。例：第一页"我是一个"、第二页"强壮的男人"，应写为 第一页 `我是一个__`、第二页 `__强壮的男人`。

二、标题与锚点（层级前缀式）
4. 遇到章节标题（含部/卷、章、节、前言、后记的标题）时，插入一行锚点注释 <!-- CHn: 标题 -->；
   **CH1 = 全书最高级标题**：有部/卷则部/卷为 CH1、章为 CH2、节为 CH3；**无部/卷的书，章直接为 CH1**（保证顶级章节在校对时转成 h1，pandoc 才能按章切分），以此类推。
5. 标题文本只出现在锚点中，正文段落里不重复标题文字。
6. 层级如实反映原书结构：看到什么层级就标什么层级，不要主观合并、拆分或升/降级。

三、内容保留
7. 保留：前言、后记（其标题按第 4 条用锚点标注层级）；各章节章号/大标题；正文段落。
8. 原书目录页照常识别为正文（是否保留由主代理后续裁决，你只需如实转录）。

四、内容去除
9. 去除：页眉、页脚（含页码）；插图（含示意图、照片）——直接忽略不写；二维码、条形码、水印、装饰线等无关标识。
10. 版权页：若整页是版权声明（含 ISBN / 版权年份 / 出版信息 / 印次号等），整页内容以单行锚点 <!-- COPYRIGHT_CANDIDATE --> 起始，交由主代理终审。

完成后按以下方式汇报：
- 若过程顺利、无阻断、无困惑：只返回一句话说明已写入的文件名，不要返回其他内容。
- 若过程中出现阻断或不确定点（如某张图片无法读取、页面内容严重残缺、或遇到无法按规则判断的情形）：如实列出阻断点与不确定点，交由主代理决定；不得自行臆断、跳过或编造内容。
```

## 覆盖对照（模板 ↔ SKILL.md）

下表逐条对应 SKILL.md「2. 子代理识图」中每个子代理负责的点，确保无遗漏：

| SKILL.md 子代理负责点 | 模板条款 |
|---|---|
| 每个子代理负责连续 10 张图片、按顺序分派 | 【负责页面】+ 逐页执行 |
| 每子代理把整批页写入同一个文件 `batch_XXX.md`（统一命名） | 【输出文件】+ 命名规范 + 逐页执行 |
| 文件内每页以 `<!-- PAGE XXXX -->` 定位（XXXX=图片文件名页码） | 逐页执行 |
| 原文一个自然段 = Markdown 一行、段落间空行 | 一、输出形式 第 1 条 |
| 禁止解释、说明、思考、元评论、页眉页脚、插图旁白 | 一、输出形式 第 2 条 |
| 跨页段落以 `__` 连接、后期合并为一段 | 一、输出形式 第 3 条 |
| 层级前缀式锚点 `<!-- CH1/CH2/CH3: 标题 -->` | 二、标题与锚点 第 4 条 |
| 标题文本只出现在锚点、正文不重复标题 | 二、标题与锚点 第 5 条 |
| 层级如实反映原书结构、不合并拆分 | 二、标题与锚点 第 6 条 |
| 保留前言/后记（锚点标注层级）、章节标题、正文段落 | 三、内容保留 第 7 条 |

| 版权页以 `<!-- COPYRIGHT_CANDIDATE -->` 标记 | 四、内容去除 第 10 条 |
| 完成后汇报规则（顺利只报文件名；遇阻断/不确定点反馈主代理） | 完成后汇报段 |

## 与 SKILL.md 的关系

- 本文件是「2. 子代理识图」环节子代理提示词的**唯一正式来源**；SKILL.md 只承载分派规则与输出约束要点，不再内嵌模板正文。
- 锚点规范（`<!-- CH1/CH2/CH3: 标题 -->`）与「内容保留 / 去除规则」的完整定义在 SKILL.md 中，子代理输出与主代理校对均以此为准。
